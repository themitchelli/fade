# FADE

**Framework for Agentic Development and Engineering**

FADE provides session memory and context management for AI coding agents like Claude Code. It solves the problem of starting every session with zero context by automatically loading project standards, progress history, and learnings from previous sessions.

## Quick Start

```bash
# 1. Clone the repo
git clone https://github.com/themitchelli/fade.git

# 2. Add to PATH (add this line to ~/.zshrc)
export PATH="$HOME/Documents/GitHub/fade:$PATH"

# 3. Reload shell
source ~/.zshrc

# 4. Initialize FADE in your project
cd /path/to/your/project
fade init

# 5. Run Claude Code with FADE context
fade run
```

## Installation

### Add to PATH

Add the following line to your `~/.zshrc` (or `~/.bashrc` for bash):

```bash
export PATH="$HOME/Documents/GitHub/fade:$PATH"
```

Then reload your shell:

```bash
source ~/.zshrc
```

Verify installation:

```bash
fade help
```

## Usage

### `fade init`

Creates the FADE file structure in your project:

```bash
cd /path/to/your/project
fade init
```

This creates four files (skips any that already exist):
- `FADE.md` - Project context for Claude
- `progress.md` - Session history log
- `learned.md` - Cumulative discoveries
- `prompt.md` - Execution instructions for Claude

### `fade run`

Starts a Claude Code session with all FADE context automatically loaded:

```bash
fade run
```

Claude will receive the contents of all FADE files and begin executing from your `prd.json`.

## File Reference

| File | Purpose | Who writes it |
|------|---------|---------------|
| `FADE.md` | Project overview, coding standards, architecture, off-limits modules, session boundaries | Human (read-only for Claude) |
| `progress.md` | Log of completed stories with timestamps | Claude (append-only) |
| `learned.md` | Discoveries and insights from sessions | Claude (append-only) |
| `prompt.md` | Instructions telling Claude how to execute FADE protocol | Generated by `fade init` |
| `prd.json` | User stories with acceptance criteria | Human creates, Claude updates `passes` field |

## How It Works

1. **`fade init`** scaffolds the file structure with templates
2. Human fills in `FADE.md` with project-specific context
3. Human creates `prd.json` with user stories (use [Ralph PRD Generator](https://github.com/themitchelli/ralph-prd-generator))
4. **`fade run`** injects all context into Claude Code
5. Claude reads `prd.json`, picks the next story, implements it
6. Claude updates `progress.md` and `learned.md` before exiting
7. Next session starts with full history and learnings
