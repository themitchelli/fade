# SKIP: US-005 AC - Search within doc with Ctrl+F

## Acceptance Criteria
Search within doc: Ctrl+F searches rendered content

## Why Not Testable
This acceptance criterion is satisfied by the browser's native Ctrl+F functionality when viewing document content in a modal. This is not custom functionality that can be tested via shell scripts.

To manually verify:
1. Start `fade dashboard`
2. Open document modal
3. Press Ctrl+F
4. Verify browser search works on rendered content
